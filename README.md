# Human

Floating macOS webcam preview window. Inspired by [hayyoth.org](https://hayyoth.org/).

## Requirements

- macOS
- clang

## Build

```sh
make
```

## Run

```sh
make run
```

Or run the binary directly:

```sh
./build/Human
```

## Install

```sh
make install
```

Copies `Human.app` to `/Applications`.
